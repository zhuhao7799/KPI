# 第一阶段验收：评分预览与结果说明

## 业务目标

考核管理员或审核人能够在不改变已冻结规则的前提下，预览一个单位的指标得分和加权总分，并理解每项分数如何进入结果。

## 验收标准

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| AC-01 | 打开页面 | 显示考核周期、单位、指标版本和两个示例指标。 |
| AC-02 | 输入 92、88 并计算 | 显示总分 90.4000；目标完成贡献 55.2000，服务保障贡献 35.2000。 |
| AC-03 | 查询健康检查 | `GET /api/health` 返回 `status: UP`。 |
| AC-04 | 传入非数字、负分或超过满分 | 后端返回 HTTP 400，说明输入不合法。 |
| AC-05 | 直接调用评分预览 API | 返回固定的周期、单位、指标版本及逐项结果；不接受客户端传入权重。 |
| AC-06 | 提交评分预览 | `POST /api/submissions` 生成提交记录，持久化规则版本、公式版本、精度和总分，并追加审计事件。 |
| AC-07 | 权限拒绝 | 结果查询人不能提交；无结果查看权限者不能读取提交；无审核权限者不能读取审计事件。 |

## 不属于本验收

该纵切面使用虚构单位和指标，不代表学校正式制度；不含登录、审批、材料上传、持久化、排名或申诉。
