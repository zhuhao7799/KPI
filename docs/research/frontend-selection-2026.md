# 高校绩效平台前端选型（2026-10-18）

## 决策

正式管理端选择 **RuoYi-Vue-Plus 官方 `plus-ui` Vue 版 6.0.0** 作为前端底座；采用其 Element Plus、VxeTable、Vue 3、TypeScript 和 Vite 技术栈。以学校品牌色、信息架构和业务页面完成视觉定制，不另行自研基础后台框架。

该决定以“与后端协同和高校业务交付”为优先级，不以单一模板视觉效果决定。

## 面向高校的落地原则

1. 统一采用“校级门户 + 业务工作台 + 任务清单 + 表单详情 + 结果分析”信息架构，避免把通用后台的菜单直接暴露给普通填报人。
2. 以深蓝、白、低饱和青绿作为品牌主题，确保可读性、打印性和长时间办公舒适度；不使用炫彩大屏风格处理考核业务。
3. 评分清单、组织树、指标树、材料目录和审核记录使用 VxeTable/Element Plus 的成熟表格、树和表单能力。
4. 动态菜单和前端权限只改善体验；证据、评分、提交、审批和下载权限仍必须由后端判定。
5. 上游许可证、版本和改造点写入项目文档；不复制未知来源商业模板或付费素材。

## 版本与验证状态

Soybean Admin 2.3.0 的调研样本已归档在工作区，项目 `frontend/` 已切换为 `plus-ui` Vue 6.0.0，并保留其 MIT 许可证与锁定提交。

`plus-ui` 已完成冻结锁文件依赖安装和生产构建。上游登录日志页有一处 Linux 大小写敏感路径问题（`logininfo` 与 `loginInfo`）；已仅修正该页面的两条本地导入路径，构建随即通过。该兼容性修正不改变上游版本选择。
