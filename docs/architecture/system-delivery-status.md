# 系统交付状态

## 当前定位

本仓库正在建设正式高校组织绩效考核系统。已交付部分是正式系统的领域核心和第一个纵切面，不是可上线成品或一次性演示。

## 已达到的正式实现标准

- 可执行的业务规则校验与自动化冒烟验证；
- 不可变的指标版本输入和提交计算上下文；
- 关系型数据库迁移、外键、约束、审计事件和 Outbox 表；
- 本地服务重启后的提交读取验证；
- 每项能力有明确验收标准。
- 业务角色、动作权限与周期/单位数据范围的分层授权模型。
- 前端、后端、基础设施和领域内核的工程边界已固定：管理端采用 plus-ui 6.0.0，服务端采用 RuoYi-Vue-Plus 6.0.0 子模块，MySQL/Redis 采用可复现的 Compose 配置。
- RuoYi 适配层已提供周期、单位、指标版本、提交、材料、待办、结果和授权管理接口，并通过补丁接入官方 RuoYi 父工程。
- 材料采用私有文件存储键和授权下载，关联操作受提交状态、上传人和指标明细约束；待办办理与提交状态变更在同一事务中完成。
- 结果查询在排序和排名前执行周期、单位和权限过滤，前端已接入填报、待办和结果页面。

## 上线前尚缺能力

- RuoYi 后端在可访问 Maven 仓库的环境中完成完整编译、启动和登录联调；当前云环境仍受外部 Maven 镜像 DNS 限制；
- 将当前本地私有材料存储替换为学校选定的 RuoYi OSS/对象存储，并完成病毒扫描、备份和容量策略；
- 将当前数据库待办桥接到学校最终选定的 WarmFlow 流程定义，补齐退回、转办、加签等制度规则；
- 用学校正式组织、用户和指标数据完成试运行、并发、审计与安全验收；
- 学校确认制度后的规则配置、迁移、试运行和安全验收。

正式系统的实现将持续补齐这些能力；任何演示数据、虚构单位和临时接口均不得作为上线数据使用。

## 当前基础框架验证

- 前端类型检查和生产构建已通过。
- 领域、应用和 JDBC 源码编译及排名、数据范围测试已通过；临时演示适配器的材料、待办和结果接口冒烟已通过。
- MySQL/Redis Compose 服务已启动并健康，V1-V7 迁移、待办唯一约束和 Warm-Flow 投影索引已在当前数据库验证。
- V7 已增加 Warm-Flow 实例/任务编号投影和幂等索引，供流程引擎接入时回写。
- Compose 配置语法和环境变量替换已通过验证。
- 后端源码已固定到官方 6.0.0 提交；当前云环境无法解析其 POM 中配置的 Maven 镜像域名，依赖解析未能完成。这是环境网络依赖问题，不改变后端基线的版本与设计；在可访问 Maven 仓库的开发环境中需完成后端编译和启动验收。
